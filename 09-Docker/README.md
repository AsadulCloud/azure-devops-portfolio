09-Docker

This folder contains Docker examples and exercises used for learning Docker fundamentals.

Subfolders:
- First-application: minimal Dockerfile example
- node-web-app: Node/TypeScript Docker examples
- python-web-app: Django example and supporting files

Usage:
- Read each subfolder's Dockerfile and run locally with Docker CLI.
- Follow README or comments inside each subfolder for specifics.

Goal: Provide runnable, well-documented examples for Docker build and run steps.
